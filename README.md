# Same Words, Different Worlds — Interactive Website

An original, responsive interactive-storytelling website for the ENGL 1301 Language Autoethnography.

## Files
- `index.html` — full essay, original reconstructed scenes, interactive moments, and Statement of Choices draft.
- `styles.css` — editorial visual design and responsive styles.
- `script.js` — interactive scenes, meaning explorer, audience switcher, reading progress, enlarged artifacts.
- `assets/images/artifact_1.png` ... `artifact_6.png` — six original illustrations from the previously prepared draft.
- `assets/video/statement-draft.mp4` — draft video statement with synthetic narration.
- `assets/audio/` — folder for your personal voice recordings (not yet included).

## Open locally
Double-click `index.html`. For the full experience, use a local server (VS Code Live Server or `python -m http.server 8000`). Then open http://localhost:8000.

## Publish on GitHub Pages
1. Create a public GitHub repository.
2. Upload the *contents* of this folder to the repository root, including `index.html`.
3. Open repository Settings > Pages. Choose Deploy from a branch, branch `main`, directory `/ (root)`.
4. Wait for GitHub Pages to provide the site URL. Test on phone and laptop.

## Important: complete this before final grading
- Get instructor approval for a custom hand-coded interactive website if needed. The assignment specifically lists site builders and requests approval for other paths.
- Add your own voice recordings for both experiences (`assets/audio/sorry-voice.mp3` and `assets/audio/pepper-voice.mp3`), along with transcript text; the player detects the files when hosted.
- Replace the draft synthetic statement video with your real 1:30–2:00 Statement of Choices, and update the peer feedback to what your classmate actually said.
- The six illustrations and reconstructed dialogue are clearly labeled, not passed off as historical photographs or transcripts of original recordings.
- Keep the full essay text visible; do not cut paragraphs to make room for animations.
- Confirm instructor/section/date and review all remembered dialogue for accuracy.

## Design basis and rights
The design is original, visually informed by the editorial, one-page visual-story structure of [HTML5 UP Story](https://html5up.net/story), scrollytelling examples, and visual essay frameworks. No third-party template source code or external photograph files are included. Six included figures and the writing were prepared for this project. Fonts optionally load from Google Fonts; local serif/sans-serif fallbacks are provided for offline viewing.

## Accessibility
Semantic landmarks, skip link, keyboard-operable buttons, reduced-motion styling, heading hierarchy, aria-pressed/aria-live feedback, descriptive alt text, transcript for the statement video. Supply captions/transcripts for any new audio/video recordings before publication.
